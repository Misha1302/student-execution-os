## Preparation checklist

Before attending:

- keep a one-page technical CV ready;
- prepare a ~30-second introduction centered on software engineering, architecture and hard systems problems rather than presenting compiler work as the only interest;
- mention the strongest proof points when relevant: Wist2 / UniversalToolchain, compiler/runtime work, MCST/LLVM-style internship experience, olympiad background, and substantial independent engineering projects;
- ask recruiters/engineers explicitly about **backend / platform / infrastructure / systems / runtime / compiler / developer-tools / performance / data** internships and junior roles;
- when a booth is business-heavy, ask whether the company has a separate tech hiring route and get the exact team/recruiter/contact instead of spending the whole conversation on an irrelevant vacancy;
- collect names/contacts and record the next action immediately after each useful conversation.
